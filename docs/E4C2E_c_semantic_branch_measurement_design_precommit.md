# E4C2E — C semantic-branch + measurement-design freeze

## Purpose

E4C2D established that the current evidence does not identify a defensible broad real-consumption-quantity coordinate for `C`.

E4C2E does not search for another workaround and does not open new values. It freezes the legitimate semantic branches, selects the unresolved/evidence-only branch as the current operating decision, and allows the project to advance to the other components without manufacturing a fifth coordinate.

## Branch 1 — Realized real consumption

**Status: preserved, not identified.**

This remains a legitimate conceptual target. Current evidence does not provide general CE quantities/unit values or a complete cross-category reference-price vector for the frozen C universe.

This branch may be reopened only after new identification evidence is precommitted.

## Branch 2 — Consumption economic command

**Status: preserved for future research.**

This asks how much non-housing consumption capacity a household can command, rather than pretending expenditure records are physical quantities.

It is not currently selected because the resource denominator, overlap with K/D/I, and equivalence-scale placement remain unresolved.

No owner/renter direction, statistical significance, geometry, or later scalar may be used to choose this branch.

## Branch 3 — C unresolved / evidence-only

**Status: selected current operating decision.**

`C` remains part of the conceptual model.

`C_COST` remains valid descriptive expenditure-flow evidence.

But:

- `C_COST` is not a real-consumption state coordinate;
- `-C_COST` is not authorized as the C state coordinate;
- CPI-deflated C_COST is not automatically real quantity;
- PCE-mapped C_COST is not automatically real quantity;
- the cost-side reference-basket track is distinct from the C state coordinate;
- no numerical C value is forced merely to complete a five-number vector.

This is an operational selection, not a permanent definition of C.

## Model implication

Five conceptual labels do not require five numerical coordinates.

An unresolved component may remain evidence-only.

C being unresolved does not block semantic and measurement research for H, I, K, or D.

It does continue to block a five-component numerical state vector and any geometry that pretends C is numerically identified.
