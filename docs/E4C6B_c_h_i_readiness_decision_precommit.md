# E4C6B — C/H/I structural readiness decision

This phase converts the exact E4C6A lineage inventory into a structural readiness decision.

The classification rules are frozen before reading the current operating decision/representation rows.

C is ready only if its current post-E4C0 lineage explicitly authorizes/fixes a numeric scalar coordinate. Historical CEX point estimates alone do not satisfy coordinate readiness.

H is ready only if the post-E4C3 lineage structurally shows a selected H_ACCESS representation, higher-is-better orientation, dimensionless status, completed inference, and evidence closeout/current operating representation.

I distinguishes **representation readiness** from **single-coordinate readiness**. A frozen pair of employment/labor-security subcoordinates may be a valid representation while still failing the requirement for one scalar `I` coordinate. No post-hoc equal-weight I scalar is permitted.

Five semantic component labels are not evidence that the state is five-dimensional.

No economic result row, sign, magnitude, significance, owner/renter direction, metric scale, covariance, or geometry result is used.
