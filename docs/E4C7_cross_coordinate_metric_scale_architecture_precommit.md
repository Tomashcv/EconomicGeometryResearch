# E4C7 — cross-coordinate metric-scale architecture precommit

E4C6E R2 froze a 40-row partial observed-coordinate registry with five numerical coordinates across four represented concepts. C remains absent, H_ACCESS remains a subcoordinate rather than the complete H state, and I remains two separate primary subcoordinates.

E4C7 occurs after those registry values have been opened. Therefore this phase is intentionally prohibited from reading registry numeric rows or choosing scale from observed sign, magnitude, dispersion, significance, owner/renter direction, or source standard errors.

The canonical metric for the current partial panel is the natural transformed-unit identity metric:

`d^2 = ΔH^2 + ΔK^2 + ΔD^2 + ΔI_FYFT^2 + ΔI_SEARCH^2`

This does not claim equal welfare importance. It means only that one unit in each previously frozen, dimensionless transformed coordinate is one metric unit. No data-fitted rescaling is introduced.

Because I contributes two numerical axes while H, K, and D contribute one each, a mandatory robustness metric is frozen:

`d_Iblock^2 = ΔH^2 + ΔK^2 + ΔD^2 + 0.5*ΔI_FYFT^2 + 0.5*ΔI_SEARCH^2`

This does not scalarize I. The two axes stay separate. It only tests sensitivity to the fact that the I conceptual block currently occupies two coordinate dimensions.

All downstream geometric claims must be reported under both metrics. A claim may be described as metric-robust only if its qualitative conclusion is unchanged under both. Choosing whichever metric produces the more attractive result is prohibited.

The metric applies to difference vectors between comparable frozen cells. No economically meaningful absolute origin is frozen here. Metric diagonality is a geometric design choice and does not assert statistical independence. Cross-survey dependence and covariance remain unresolved and are the next workstream.

No geometry, dimensionality test, real-inflation estimate, or final scalar is authorized by E4C7 itself.
