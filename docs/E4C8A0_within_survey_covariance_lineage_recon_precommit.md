# E4C8A0 — within-survey covariance lineage reconnaissance

E4C8 established that exactly two off-diagonal covariance families are potentially recoverable from same-survey designs: K-D in SCF and I_FYFT-I_SEARCH_SECURITY in CPS.

Before freezing formulas, the exact pre-existing replicate/implicate source lineage must be recovered. The current 40-row registry contains only marginal point states and standard errors, so it is not sufficient by itself for joint covariance.

E4C8A0 is value-free reconnaissance. It may inspect full static code/document/metadata text, but data/result tables are limited to their header line. No economic numeric row, replicate value, implicate value, or covariance value may be opened.

The output inventories:
1. scripts containing both target variables and replicate/implicate machinery;
2. data/result files whose filenames or statically referenced paths are relevant;
3. exact header schemas of text candidates;
4. static path references found in relevant scripts.

No covariance formula is frozen by A0. No covariance execution or geometry is authorized. The inventory is intended to support a subsequent E4C8A formula-and-lineage precommit without outcome peeking.
