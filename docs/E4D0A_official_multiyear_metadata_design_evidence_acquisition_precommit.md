# E4D0A — official multiyear metadata + design evidence acquisition

E4D0A is an acquisition phase only.

The first temporal extension is frozen structurally as the adjacent 2019→2022 pair. This choice uses no economic values: 2022 is the existing frozen anchor, while 2019 is the immediately preceding SCF wave and has matching ACS 1-year and CPS ASEC releases.

Before any download, E4D0A freezes exact official URLs and evidence roles for both years across all three survey families.

The acquired material is documentation only: release pages, dictionaries/codebooks, user or technical guides, sample-accuracy/standard-error material, survey-change documents, and replicate-layout metadata. No ACS, SCF, or CPS microdata file is authorized or downloaded.

A successful acquisition does not imply that 2019 and 2022 are comparable. It only creates a hash-pinned evidence bundle for E4D0B. E4D0B must adjudicate all E4D0 comparability axes before a common-year grid or any additional-year economic value can be authorized.
