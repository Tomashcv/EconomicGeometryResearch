# E4D1AR — SCF effective source-lineage forensic

E4D1A resolved five of six 2019 source requirements. Requirement 3 remained unresolved because the 2022 filesystem contains both `scfp2022s.zip` and `scf2022s.zip`, while both corresponding 2019 official links exist.

E4D1AR resolves only that ambiguity. It freezes the evidence hierarchy before opening any additional static lineage content.

Filesystem presence has zero selection weight. The preferred evidence is the frozen E4A2F K/D executor's effective data-read lineage. If that is not explicit enough, phase-local E4A2F contracts/docs/metadata may establish the source. A third admissible route is frozen target-variable source schema showing FIN and PIRTOTAL jointly attributed to exactly one source family.

Static evidence may be read only under scripts, docs, and data/metadata. No raw archive content and no numeric result rows may be opened. Existing E4D1A structural result rows are allowed only to preserve the five already-resolved requirements and the exact unresolved requirement.

A candidate is selected only if the admissible evidence identifies exactly one effective K/D source family. If evidence remains tied or insufficient, requirement 3 stays unresolved and the next route is E4D1AR1. No outcome values, convenience, file size, or filename similarity may break the tie.

If requirement 3 resolves, the other five E4D1A requirements remain byte-semantically unchanged and E4D1B becomes authorized to precommit exact 2019 data acquisition and schema audit. E4D1AR itself downloads no data.
