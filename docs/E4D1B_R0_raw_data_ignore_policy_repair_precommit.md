# E4D1B R0 — raw-data Git-ignore policy repair

The first E4D1B attempt halted before the E4D1B scientific precommit and before any network download because the first selected raw-data destination was not ignored by Git.

R0 changes only repository tracking policy. It adds exact anchored ignore rules for the six already-frozen 2019 raw-data destinations. It does not broaden the scientific source universe, change any URL, change any schema rule, download any data, or open any 2019 value.

The original E4D1B terminal wrapper is reused after the repair. Its SHA256 is frozen by R0. Because R0 necessarily creates new commits, the resumed copy may change only the administrative parent-HEAD literal from the old E4D1AR2 freeze HEAD to the new E4D1B-R0 freeze HEAD. Every occurrence of that exact old 40-hex parent literal must be replaced, and no other byte-level transformation is permitted.

The resumed E4D1B therefore retains the same six official URLs, local raw paths, schema-only boundary, no-row-read policy, and downstream routing rules.
