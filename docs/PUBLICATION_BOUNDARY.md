# Publication boundary

This repository is a curated public portfolio view of a larger research workspace.

## Included

- Python research and audit scripts;
- methodology and precommit documents;
- small macro-level processed tables;
- selected frozen aggregate outputs;
- public integrity tests.

## Excluded

- the `data/raw/` acquisition tree;
- downloaded survey microdata and source archives;
- large replicate-statistic ledgers not needed to understand the portfolio;
- local execution logs and machine-specific metadata;
- absolute workstation paths;
- generated provenance files that only describe the private/local filesystem.

The exclusion of raw data is intentional. Reproducibility here means exposing the research logic, frozen contracts and selected derived evidence while requiring source datasets to be obtained from their original authorities.

No credentials, API keys or private account data are part of this project.
